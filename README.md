# HR Attrition Prediction Application

End-to-end HR employee attrition prediction using **Python**, **Streamlit**, **SQLite**, and **scikit-learn**.

Predict whether an employee is likely to leave, view confidence scores, and review prediction history stored in a local database.

---

## Features

- Streamlit web UI with employee input form  
- Logistic Regression model (~86% test accuracy on hold-out data)  
- SQLite storage for employee data and prediction history  
- Dashboard with metrics, charts, and prediction table  
- Modular codebase aligned with `notebook/hr_attrition_analysis.ipynb`

## Architecture

```
User
  ↓
Streamlit (app.py)
  ↓
prediction_service.predict_and_store()
  ├─► preprocess.py → predictor.py → models/*.pkl
  └─► database.py → employees.db (prediction_history)
  ↓
history_dashboard.py → Prediction history tab
```

## Quick start

### Option A — Automated setup

```bash
cd hr_attrition_project
bash scripts/setup_project.sh
source venv/bin/activate
streamlit run app.py
```

### Option B — Manual setup

```bash
cd hr_attrition_project

# 1. Virtual environment
python3 -m venv venv
source venv/bin/activate

# 2. Dependencies
pip install --upgrade pip
pip install -r requirements.txt

# 3. Database
python scripts/init_database.py

# 4. Train model
python scripts/train_model.py

# 5. Run app
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

See **[SETUP.md](SETUP.md)** for full details, troubleshooting, and testing.
